Autofill via browser extension
One-time setup: open chrome://extensions, enable "Developer mode" (top right), click "Load unpacked", and select the extension/ folder from the project. Then, on any real job application page (even ones with an embedded iframe form, like Greenhouse), click the extension's icon in your toolbar and hit "Autofill this page" - it reads the application ID from the page URL (opened from an email link) and fills the form directly, including inside iframes. (The earlier bookmarklet approach doesn't work for iframe-embedded forms - browsers block that at the JavaScript level; the extension can reach inside because it's injected per-frame by the browser itself.)
